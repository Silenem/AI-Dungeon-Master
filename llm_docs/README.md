# Как подключить ИИ-Мастера к игре

Для первой браузерной версии я бы выбрал **облачный API с оплатой за токены**. Команда и игроки смогут открыть одну игру без установки моделей на свои компьютеры. Если нужен рублёвый биллинг, первый кандидат для прогона на наших сценах — **Alice AI LLM Flash в Yandex AI Studio**. При принятом ниже объёме текста 1 000 ходов стоят около **260 ₽**. Второй кандидат — **GigaChat через Cloud.ru**. Качество русского повествования и разбора действий на наших сценах ещё предстоит измерить. [Тарифы и расчёт стоимости хода](pricing.md)

Для **автономной версии** я бы сохранил тот же Go-бэкенд и подключил **Ollama с локальной Qwen3 4B**, затем сравнил её с 8B на тех же сценах. Модель запускается рядом с Go на машине ведущего или на сервере команды. Игроку достаточно браузера. На текущем ПК есть GTX 1070 с 8 ГиБ, но установленный драйвер ниже минимума, указанного Ollama для этой карты. [Варианты локального запуска и проверка оборудования](local.md)

## Два варианта одного игрового хода

**Полный вариант.** Первое обращение к LLM превращает свободный текст в описание цели, способа и используемого предмета. Go проверяет факты сцены, выбирает Силу, Ловкость или Волю, при необходимости бросает кубик и сохраняет исход. Второе обращение получает только подтверждённые последствия и превращает их в реплику ИИ-Мастера. Облако и локальный сервер могут обслуживать оба запроса. [Правила проверки действия](../docs/dnd-5e/README.md#как-выбрать-проверку-действия-игрока)

**Упрощение для одного приключения.** Можно начать с тех же двух запросов к одному облачному API. Это сохраняет свободный ввод и избавляет команду от развёртывания весов к первому показу. Если небольшой локальной модели трудно одновременно выдерживать стиль рассказа и правила сцены, ещё один вариант — оставить ей распознавание действия, а ответы на несколько подготовленных исходов взять из сценария. Такая версия экономит один вызов на подходящих ходах, но повествование становится менее разнообразным.

**Смешанный вариант.** Локальная модель разбирает намерение, облачная пишет рассказ, либо наоборот. Бюджет считают отдельно для каждой части хода. В облако достаточно передавать факты текущей сцены и короткую сводку прошлых решений. Между провайдерами имеет смысл переключаться между вызовами. При повторном запросе к рассказчику Go передаёт уже сохранённый результат броска.

## Как сравнить кандидатов до выбора

Провести одинаковые прогоны на русском для взлома двери с отмычкой и без неё, магии без нужного заклинания, расплывчатого «хочу пройти», разговора со стражником и повторного входа после сохранения. На каждом примере сравнить распознанный способ с ожидаемым, проверить формат ответа и отметить, придумала ли модель отсутствующий предмет или исход. Отдельно замерить время до первых слов рассказчика, время всего хода, потребление токенов и паузу после простоя. Приведённые цены и характеристики основаны на документации и расчётах. Игровых замеров для этих моделей пока нет.
