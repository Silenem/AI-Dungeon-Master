# Сколько стоит ход ИИ-Мастера

Срез публичных цен на 9 ноября 2026 года. Для сопоставления возьмём одиночное приключение длиной **50 ходов**, а для месячного примера — **20 таких прохождений**, всего 1 000 ходов. Это сценарий расчёта. Реальные игроки могут писать более длинные реплики, а токенизаторы разных моделей по-разному делят русский текст.

## Единица сравнения

| Обращение за один ход | Вход | Оплачиваемый выход |
| --- | ---: | ---: |
| Разбор действия игрока | 600 токенов | 50 токенов |
| Рассказ с результатом от Go | 1 400 токенов | 250 токенов |
| **Итого за ход** | **2 000** | **300** |

Вход включает инструкции, состояние сцены и нужную историю в каждом обращении. Цена хода при ставках за миллион токенов равна `(2000 × цена входа + 300 × цена выхода) / 1 000 000`. Рассчитан обычный интерактивный вызов по полной ставке, без попадания в кеш, batch-скидок и внешних инструментов. В 300 токенов входят все оплачиваемые токены вывода. Если модель дополнительно расходует токены на рассуждения, фактический счёт растёт. Повторный сетевой вызов также может увеличить расход.

[Groq Structured Outputs](https://console.groq.com/docs/structured-outputs) · [DeepSeek JSON Output](https://api-docs.deepseek.com/guides/json_mode/)

Если команда разворачивает игру из РФ, Россия отсутствует в опубликованных списках поддерживаемых стран Gemini API и OpenAI API на дату проверки. Для такого размещения рублёвые API и автономная модель дают более прямой путь к показу. [Google AI Studio](https://aistudio.google.com/docs/pricing#gemini-3.1-flash-lite) · [регионы Google](https://aistudio.google.com/docs/available-regions) · [регионы OpenAI](https://developers.openai.com/api/docs/supported-countries/)
