# Смета Cloud.ru на две недели тестирования жюри

Срез публичных тарифов на **27 ноября 2026 года**. Суммы в рублях, с НДС и без грантов. В базовом сценарии из 500 ходов проект обходится примерно в **3 048–3 349 ₽ с API** при ставках от gpt-oss-120b до Qwen3.6‑35B-A3B или **3 548–5 145 ₽ со своей Qwen 4B–35B**, если GPU работает суммарно 15 часов. Для планирования с запасом — **4 000 ₽ с API** или **5 000–6 000 ₽ со своей Qwen 8B–14B** при базовой нагрузке.

## Готовая модель через Foundation Models API

Для сравнения берём три обращения на ход. Разбор действия — 600 входных и 50 выходных токенов, рассказ по результату Go — 1 400 и 250, классификация памяти — 500 и 50. Всего **2 500 входных и 350 оплачиваемых выходных токенов на ход**. Расчёт идёт по полным ставкам. Токены рассуждений и повторные вызовы, если они возникнут сверх этого объёма, увеличат расход. Добавляются кэш по 0,01586 ₽ за ГБ в час и 15,616 ₽ за миллион запросов. Если в аккаунте доступен Shared A100 PCIe, ставка на VRAM составляет 3,965 ₽ за ГБ в час. ## Как держать расходы под контролем

- Для показа жюри брать API по токенам. Для демонстрации своего инференса начать с Qwen3‑14B и сравнить её с Qwen3‑8B на русском повествовании и разборе игровых действий.
- В ML Inference установить минимум 0 и максимум 1 реплику. Для базовой оценки принять 5 минут ожидания после запроса и проверить доступную настройку в консоли. Проверки доступности направлять на Go. Фоновые задания из очереди памяти по возможности обрабатывать, пока модель уже работает.
- Перед назначенным показом можно прогреть модель заранее и включить это время в счёт. При холодном запуске Cloud.ru допускает ответ 502. Повтор вызова в Go должен использовать тот же ID хода, чтобы результат игры применялся один раз. [Холодный старт](https://cloud.ru/docs/ml-inference/ug/topics/troubleshooting__request-waiting-error) · [Сохранение и повторы](data-model.md#как-проходит-сохранение)
- Стартовый грант 4 000 бонусов при наличии и применимости может покрыть CPU-инфраструктуру. По правилам гранта Foundation Models, ML Inference и GPU-ВМ исключены. [Условия стартового гранта](https://cloud.ru/docs/billing/ug/topics/concepts__start_grant)
